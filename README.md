✨ 无后端、纯静态、零服务器、支持 EdgeOne/Cloudflare 一键极速部署的现代化相册托管系统

🚀 双平台一键部署核心优势
本项目深度适配 腾讯云 EdgeOne 与 Cloudflare 两大静态托管平台，区别于传统 GitHub Pages 部署，拥有更强的加速能力、稳定性与功能性，适配不同使用场景。
1. 腾讯云 EdgeOne 部署（本站预览采用方案）
核心定位：国内用户首选、低延迟、高稳定、极速访问
- 国内节点全覆盖：依托腾讯云国内海量边缘节点，彻底解决 GitHub Pages 国内访问卡顿、超时、加载失败问题
- 超低访问延迟：静态资源、图片文件就近缓存分发，国内首屏加载速度提升 80% 以上，大图秒开无卡顿
- 稳定防拦截：规避海外静态站点国内访问不稳定、偶尔丢包的问题，全年高可用
- 免费额度充足：个人用户免费流量、带宽完全满足日常相册使用，无额外成本
- 一键自动部署：关联 GitHub 仓库后，代码更新自动同步、自动构建、自动发布，无需手动操作
- 支持自定义域名：免费配置专属域名，自带 HTTPS 加密，访问更正规、稳定
2. Cloudflare 部署（海外首选、全球分发）
核心定位：全球访问、免费不限量、海外极速响应
- 全球节点覆盖：遍布全球的边缘网络，海外用户访问延迟极低，适配跨境分享场景
- 免费无流量限制：无带宽、流量额度限制，海量图片、高频访问无需担忧超额收费
- 高防安全加持：自带 DDoS 防护、CC 防护，有效抵御恶意访问与攻击
- 零配置开箱即用：绑定仓库即可自动部署，全程无需服务器、无需运维
- 智能缓存策略：自动缓存静态资源与图片，重复访问极速响应，提升用户体验
双平台部署对比总结
- 国内个人使用、追求极致速度：优先选择 EdgeOne（本站同款部署方案）
- 海外访问、长期海量流量、无成本需求：优先选择 Cloudflare

📖 极简 Fork 使用方法（支持无缝同步项目更新）
本项目支持自定义相册目录+无痛同步官方更新，无需修改源码核心逻辑，只需简单修改目录名称，即可实现「个人资源独立存储+项目功能持续更新」，彻底解决 Fork 后更新冲突、数据混淆问题。
核心原理
默认相册存储目录为 public/albums，用户可自行修改为任意自定义目录名，个人图片资源独立存放，后续拉取项目官方更新时，不会覆盖、丢失个人相册数据，完美适配长期使用。
详细操作步骤
1. Fork 本项目：点击仓库右上角 Fork 按钮，将项目复刻至自己的 GitHub 账号下
2. 清理默认资源（二选一即可）
方式一（快速清理）：直接删除 Fork 后仓库内 public/albums 目录下所有文件夹、文件，清空默认示例资源
方式二（推荐、长期最优）：保留默认目录，修改全局相册路径，彻底隔离个人数据
3. 自定义专属相册目录
进入 Fork 后的项目，分别编辑两个核心文件：
1. index.html：全局搜索 public/albums，替换为自己自定义目录名（例：public/myphoto、public/gallery）
2. admin.html：全局搜索 public/albums，同步替换为上述自定义目录名
全程仅修改目录字符串，无需改动任何代码逻辑。
4. 创建个人目录：在仓库public 文件夹下，新建刚刚自定义命名的空目录，作为专属图片存储根目录
5. 后续同步更新：项目官方迭代新功能、修复BUG后，直接拉取官方更新同步到自己的 Fork 仓库即可，个人自定义目录、相册图片数据完全保留，功能同步更新无冲突
使用优势
- 数据完全隔离：个人相册资源与项目默认示例资源彻底分离，干净整洁
- 无痛更新迭代：无需手动迁移数据、无需重构代码，一键同步官方所有更新
- 零配置高灵活度：目录名可自定义，适配个人相册、分类相册、多场景使用
- 永久保留数据：不受项目更新、重置代码影响，个人图片资源安全稳定

📁 项目架构说明
本项目由两个独立 HTML 页面 组成，各司其职、完全解耦，适配双平台静态托管特性，无任何动态服务依赖：
1. 前台展示页（index.html）
面向普通访客，用于浏览相册、查看图片、预览详情，轻量化无权限操作，适配边缘缓存加速。
核心定位：静态展示、轻量化、高适配、极速访问
前台前端实现细节
- 自定义目录适配：支持全局自定义相册根目录，完全适配用户个人命名目录，不影响核心功能
- 本地目录扫描机制：通过 Vite 原生 import.meta.glob 扫描自定义图片目录结构，无需后端接口
- 前端树形目录构建：原生 JS 递归遍历文件夹，自动生成层级化相册目录树
- 智能封面图算法：自动抓取文件夹首张图片作为缩略封面，界面规整美观
- Canvas 缩略图压缩渲染：前端实时压缩生成固定尺寸缩略图，大幅降低资源加载体积，适配边缘加速
- EXIF 元数据解析：基于 piexif.js 本地解析图片拍摄信息，无需服务端处理
- 无刷新图片切换机制：内存索引切换图片，不刷新页面、不改动路由，浏览体验流畅
- Viewer.js 全屏预览：支持手势缩放、键盘翻页、图片旋转，专业级看图体验
- 图片直链复制：一键复制公网 CDN 图片地址，方便复用分享
- 日期前缀自动剥离：支持手动切换文件夹日期前缀显示/隐藏，优化UI展示效果
2. 后台管理页（admin.html）
面向管理员，提供完整云端文件管理能力，所有增删改查操作均通过前端请求 GitHub API 完成，适配双平台纯静态运行环境，完美适配用户自定义相册目录。
核心定位：纯前端云端资源控制台、轻量化相册管理后台
后台整体风格
- 现代扁平化极简管理界面，清爽无冗余元素
- 侧边栏树形目录 + 顶部面包屑导航 + 主内容区经典三分布局，操作逻辑清晰
- 图标视图、列表视图双模式自由切换，适配不同管理场景
- 全局右键菜单、鼠标框选、批量任务面板，高效批量管理
- 全局加载状态锁、操作防抖、任务队列机制，避免操作冲突
后台前端实现原理
- 纯前端 API 交互：基于 Fetch 直接请求 GitHub 官方 REST API，完成所有文件增删改查，无后端中转
- 自定义目录兼容：全局适配用户自定义相册根目录，所有上传、遍历、删除操作精准匹配个人目录
- 本地配置导入机制：支持上传 TXT 配置文件，自动加载仓库地址与密钥，配置简单便捷
- 递归目录扫描引擎：前端深度遍历自定义目录下所有层级文件夹与图片文件，精准同步目录结构
- 前端模拟文件系统：复刻本地资源管理器操作逻辑，上手零学习成本
- Base64 数据清洗修复：自动修复 API 上传异常，杜绝空文件、损坏文件问题
- 独立任务队列系统：上传、复制、剪切、删除、下载全流程队列化管理，避免请求拥堵
- 任务全量管控：支持任务中断、失败重试、一键清空，适配批量大量操作
- 原生拖拽框选算法：纯 JS 实现鼠标选区多选文件，高效批量操作
- 内存剪贴板功能：前端模拟复制/剪切缓存，支持跨目录粘贴移动文件
- 智能日期文件夹：新建文件夹自动生成标准日期前缀，规整相册分类
- 全局防重锁机制：任务执行期间锁定操作，防止高频请求触发 API 风控
- 超时防护机制：10秒加载超时自动终止，避免页面卡死、无响应问题

🚀 双平台一键部署教程
通用前置准备
- 完成上方 Fork、自定义目录、新建个人相册目录操作
- 生成具备 repo 权限的 GitHub Token，新建 config.txt 配置文件备用
https://github.com/用户名/仓库名
ghp_你的密钥

方案一：EdgeOne 一键部署（国内首选｜本站同款）
1. 登录腾讯云 EdgeOne 平台，进入「静态网站托管」功能
2. 绑定自己 Fork 后的 GitHub 仓库，授权平台读取仓库代码
3. 开启自动部署，选择对应部署分支，无需修改任何配置
4. 等待10-30秒自动构建完成，即可生成默认访问链接
5. 可选：配置自定义域名，平台自动配置HTTPS证书，开启国内边缘加速
6. 访问 域名/admin.html，上传 config.txt 完成后台初始化，即可全功能使用
方案二：Cloudflare 一键部署（全球首选｜不限流量）
1. 登录 Cloudflare 平台，进入 Pages 静态托管服务
2. 点击「创建项目」，绑定自己 Fork 后的 GitHub 仓库并授权
3. 无需修改构建命令与输出目录，默认配置即可直接部署
4. 等待自动部署完成，生成全球加速访问链接
5. 可选：绑定自定义域名，开启全球CDN缓存与安全防护
6. 进入后台页面加载配置文件，完成初始化后即可正常使用
